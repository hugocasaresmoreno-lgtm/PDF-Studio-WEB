PDF Studio

Tu aplicación ligera y rápida para leer y editar archivos PDF en Windows.

Descargar para Windows (.exe)
¿Cómo descargar e instalar la app?
  1. Haz clic en el botón azul de descarga para obtener el archivo instalador (.exe).
  2. Si tu navegador o Windows muestran una advertencia de seguridad (aviso típico en aplicaciones nuevas), haz clic en los tres puntos (...), selecciona Conservar y después Conservar de todos modos.
  3. Haz doble clic en el archivo descargado para ejecutar la instalación en tu ordenador.
Sobre la versión en navegador web: PDF Studio está optimizado como aplicación de escritorio independiente para ofrecer un rendimiento fluido en Windows. Próximamente se evaluará soporte ampliado para navegadores web estándar.
